Trabalho do 2º bimestre de Modelos e Linguagem de Programação III, Multivix Vitória, 2026/2.

Projeto inicial: Spring Boot, entidade `Cliente`, `ClienteRepository` e MySQL no Docker. O README completo entra com a última parte.
